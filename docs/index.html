The path to the DAC

Three ways out. Start with Shared.

Same language as Audio Harbor on the Mac. If you are unsure, leave Shared on — that is the daily driver on every machine.

Shared
◇

Everyday listening — recommended

Plays like any other process. Calls, browser, speakers, Bluetooth still work. Honest default when there is no dedicated DAC.

Exclusive
◎

Bit-perfect into a USB DAC

Native stacks take the device: Core Audio hog, ALSA hw:, WASAPI Exclusive. Sample rate follows the file. DSD converts to PCM on this path.

DoP
☾

Exclusive, plus real DSD

DSF, DFF, and SACD ISO reach a DSD DAC as DoP. Pick it only if the DAC plays DSD. The conversion badge always says which path you are on.

Exclusive and DoP use the platform stack — Core Audio, ALSA, or WASAPI. More in the README.

Native audio

One stack per OS. No portable detour.

The host talks to the same I/O the DAC expects — Exclusive and DoP without a middle graph.

macOS

Core Audio

Hog mode for Exclusive. DoP into a DSD DAC. Rate follows the file.

Linux

ALSA

hw: / plughw: for Exclusive and DoP. Shared uses the system default when you want it.

Windows

WASAPI

Shared, Exclusive, and DoP on the native path. Unpack the zip and run start.cmd.

≡

Network players and DLNA

A streamer or network amp is an output like a DAC: files go out untouched, DSD as DSD when the player takes it — else clean PCM, or DoP for a DAC behind it — gapless where the player can. Optional UPnP server so a phone can browse the same library.

○

No account

No streaming services. No telemetry of what you play. Open source on GitHub.

Formats

What it will play

The files on your disks — not a converter suite in the main path.

PCM, as written

FLAC · ALAC · WAV · AIFF · AAC/M4A · MP3. Gapless where the format allows.

DSD, with a label

DSF, DFF, SACD ISO (including DST). Output DoP sends real DSD; Shared and Exclusive convert to PCM.

Not in the main path

No upsampling theatre, no Qobuz/Tidal. Those dilute the local-first promise.

What the badge is for

Shared, Exclusive, DoP, or an honest DSD→PCM label — so you are never guessing what left the host.

One host

Wherever the library lives.

Same Harbor language as Audio Harbor — without a SwiftUI shell on the host. The browser (or iOS app) is the remote; the machine is the DAC host.

Apple Silicon & Intel

macOS
