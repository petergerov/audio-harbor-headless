Audio Harbor Headless installs a ready-to-run host under:

/usr/local/audio-harbor-headless

After install:

  1. Optional: copy config.example.toml → ~/.audio-harbor-headless/config.toml and set library.roots
  2. Audio Harbor appears in the menu bar (speaker icon): start / stop the server, show the QR code for the iPhone, open Settings
  3. Or in Terminal: audioharbor to start, Ctrl+C or audioharbor stop to stop

Node.js is bundled. No separate Node install required.
